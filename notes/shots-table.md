# シュートの表（`data/shots.csv`）

`events.zip` からシュートを抜き出した表。1行 = シュート 1本。作り方の決めごとは [decisions/0002](../decisions/0002-shots-table.md)。`mise run shots` で作り直せる。

- 元データ: Wyscout の公開データ（Pappalardo ほか 2019、figshare v5、CC BY 4.0）を加工したもの
- 行: 45,945本（`shot` 43,078・`free_kick` 2,209・`penalty` 658）。ゴールは `shot` 4,492・`free_kick` 137・`penalty` 477
- 並び: 大会の名前の順、その中は元データの並び（試合・前後半・時刻の順）
- 書き方: 真偽は `0`/`1`、値がなければ空欄。DuckDB などは空欄を NULL として読む

## 列

| 列 | 型 | 意味 |
| --- | --- | --- |
| `shot_id` | int | イベントの ID（元データの `id`） |
| `competition` | str | 大会。`England`・`France`・`Germany`・`Italy`・`Spain`（2017/18 シーズン）、`World_Cup`（2018）、`European_Championship`（2016） |
| `match_id` | int | 試合の ID（`matches.zip` の `wyId`） |
| `match_period` | str | `1H`（前半 21,166本）・`2H`（後半 24,621本）・`E1`・`E2`（延長の前半 34本・後半 48本）・`P`（PK 戦 76本） |
| `event_sec` | float | 前後半それぞれの始まりからの秒数（小数 3桁） |
| `team_id` | int | 打ったチームの ID |
| `player_id` | int | 打った選手の ID。名前は入れていない（`players.json` の `wyId` でつながる） |
| `shot_type` | str | `shot`（普通のシュート）・`free_kick`（直接フリーキック）・`penalty`（PK） |
| `x` | int | 打った位置の縦（0〜100。攻める向きにそろっていて、相手のゴール側が 100） |
| `y` | int | 打った位置の横（0〜100） |
| `body_part` | str | `left_foot`・`right_foot`・`head_or_body`（タグ 401・402・403）。3種類とも全部に付いている |
| `is_counter_attack` | 0/1 | カウンター攻撃のタグ（1901）。`shot` の 2,403本に付いている |
| `prev_event` | str | 同じチームの直前のイベントの種類（元データの `subEventName`）。試合・前後半の始めのシュートは空欄 |
| `prev_seconds_before` | float | その直前のイベントが何秒前か。`prev_event` が空欄なら空欄 |
| `is_goal` | 0/1 | ゴールになったか（タグ 101）。答え |

入れていないもの（シュートのあとに決まる）: ゴールのどこに飛んだか（タグ 1201〜1223）、枠内か（1801・1802）、ブロックされたか（2101）、終わりの位置、タグ 201 Opportunity。

## 作るときに数えたこと（2026-11-08）

### 直前のイベント（イングランドの `shot` 8,451本）

- 1つ前のイベントをそのまま見ると、同じチーム 5,621本・相手チーム 2,829本・前がない 1本。相手チームのものは守備のデュエル（1,009）・空中戦（539）・クリア（383）など
- 相手のイベントを飛ばして同じチームの直前を見ると、8,450本で見つかる（見つからない 1本は、試合のキックオフから 1.2秒のシュート）。間は中央値 1.6秒・99% が 6.1秒以内・10秒を超えるのは 23本
- 種類はパス（2,072）・地上の攻めのデュエル（1,896）・空中戦（1,178）・クロス（1,019）・スマートパス（360）・こぼれ球のデュエル（329）・シュート（297。こぼれ球の打ち直し）・コーナー（262）など
- 表全体（45,945本）では、直前が空欄のシュートは 11本（うち 7本はフリーキックか PK）。直前のイベントの種類は 33

### タグ 201 Opportunity（7大会の `shot` 43,078本）

| | 本数 | ゴール | 枠内（1801） | ブロック（2101） | x が 94 以上 |
| --- | --- | --- | --- | --- | --- |
| 201 あり | 30,458 | 4,470（14.7%） | 15,164（49.8%） | 2,423（8.0%） | 4,524（14.9%） |
| 201 なし | 12,620 | 22（0.2%） | 156（1.2%） | 7,799（61.8%） | 310（2.5%） |

201 は、ブロックされずにゴールのほうへ飛んだかを、結果を見て付けた印と推定した。特徴に入れると答えをほぼ見ることになるので、表に入れていない。

### ID の型

シュートの 3種類（45,945件）では、`id`・`matchId`・`teamId`・`playerId`・`eventId`・`subEventId` はすべて数値だった。型の揺れ（文字列・空文字）は、ほかの種類のイベントやファイルのもの（[wyscout-data-columns.md](./wyscout-data-columns.md)）。表を作るときは、念のため数値に直している。
