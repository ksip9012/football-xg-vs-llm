# Gemini の 500本の試し（2026-11-08）

決めごとは [decisions/0006](../decisions/0006-compare-with-llm.md)。最初の xG と同じテストのシュートから 500本を選び、Gemini 3.8 Flash（Vertex AI）に、統計モデルと同じ 3つの情報（ゴールまでの距離 m・ゴールの見える角度（度）・頭か足か）だけを渡して、ゴールになる確率を答えさせた。統計モデルは、同じ 500本の交差検証の xG（`data/xg_stat.csv`）。

- 考える量（thinking）を LOW・MEDIUM・HIGH の 3通り（`gemini-3.8-flash` は MINIMAL を受け付けなかった）。LOW はもう 1回、順番の混ぜ方だけを変えて動かした（2回聞いたときの揺れを見るため）
- 1回に 50本、順番を混ぜて送り、ID は送るときだけ連番にした。答えは `data/llm_runs/trial/` に 1回ごとに残してある
- 作り直し方: `mise run llm-trial`（答えのファイルがあれば API は呼ばずに表だけ出す。消すと、もう一度料金がかかる）

## 決めたこと

本番（テストの 8,626本）は、**考える量 LOW・1回に 50本**で動かす。

- LOW は MEDIUM・HIGH と物差しがほぼ同じで、費用と時間がいちばん小さい（HIGH は LOW の 14倍の費用、13倍の時間で、物差しは少し悪いくらい）
- 答えの抜け・形の崩れは、4回の 2,000本で 0 だった。50本ずつで問題なかった

## まとめ

- **Gemini は、統計モデルとほぼ同じくらい当てた**。物差しでは少し上回っているようにも見えるが、500本・ゴール 52本では、この程度の差は偶然で動く（LOW を 2回動かすと、ログ損失は 0.2737 と 0.2706）。どちらが良いかは、本番で差の 95% の幅を出してから言う
- **答え方は統計モデルとよく似ている**（相関 0.98）。距離と角度から確率を出す形は、データから作った xG とほとんど同じ
- **ただし、全体に低めに出す**。確率の平均 0.085〜0.091 に対して、実際のゴールの率は 0.104。順位付け（AUC）は良いのに、確率の高さが少し低い
- **考える量を増やしても良くならなかった**。LOW では思考のトークンは 0 で、実質「考えない」設定だった（推定）
- **揺れは小さい**: 2回聞いたときの相関 0.986、差の絶対値の平均 0.0105、最大 0.109

試し全体の費用は $0.88（HIGH が 8割）。単価は 2026-11-03 に Step2 で確かめた値（100万トークンあたり入力 $0.75・出力 $3.75。思考は出力として数えた）で、今の単価はまだ確かめていない。
