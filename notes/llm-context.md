# 直前のプレーとカウンターを足して、統計モデルと Gemini を比べる（2026-11-15）

## 読み方

- **Gemini は、足した情報の向きはわかっている**（推定）。スルーパスのあと（0.107 → 0.166）とカウンター（0.077 → 0.104）では確率を上げ、コーナー（0.101 → 0.071）と空中戦（0.117 → 0.092）では下げた。統計モデルの係数の向き（スルーパス・カウンターはプラス、コーナー・空中戦はマイナス）と同じ
- **ただし、大きさが合わない**。スルーパスのあとは統計モデルとほぼ同じところまで上げたが、こぼれ球（実際 0.246）はほとんど上げなかった（0.197 → 0.206）。浮き球のパスは、実際は 0.129 なのに下げた（0.090 → 0.075）
- **低めに出すくせが強くなった**。確率の平均は 0.092 → 0.087（実際の率の 0.83倍）。ふだんのパスやドリブルのあとを、さらに低く見積もった。下げた分が上げた分より大きく、全体ではよくならなかった（推定）
- 統計モデルの係数は、データから見た「同じ距離・角度でもどれだけ決まりやすいか」。スルーパスのあと（1.42倍）とカウンター（1.74倍）は、守備の人数が少ない状況を表していると読める（推定）。コーナー（0.42倍）と空中戦（0.50倍）は、競り合いの中で打つので決まりにくい
- `other`（テストで 9本）は本数が少なく、係数も確率も当てにならない

## 読み方の注意

- 1回の分け方のテスト（388試合）での比べ。Gemini の答えは 1回分
- 組のまとめ方（decisions/0007）で結果は変わりうる。まとめ方は、結果を見る前に決めた
- 統計モデルの「よくなった」は、ログ損失の差の幅の端がほぼ 0 で、ぎりぎり
- 直前のプレーから何秒たったか、選手やチームの情報は、どちらにも渡していない
