# 最初の xG（ロジスティック回帰）の結果と読み方（2026-11-08）

決めごとは [decisions/0004](../decisions/0004-first-xg-three-ways.md)。下の「出力」は `mise run xg` の結果をそのまま貼ったもの（時間はこの Mac での 5回の中央値で、動かすたびに少し変わる）。

## まとめ

- **3通りの答えは一致した**: 係数の差は、numpy と statsmodels で 1e-15 ほど、scikit-learn と 2e-5 ほど。テストの確率の差は最大 1e-5 で、物差しは 3通りとも同じ。違いは作り方だけ
- **速さ**: numpy 3〜4ms、statsmodels 9ms ほど、scikit-learn 15〜22ms ほど（4万本・特徴 2〜3個。どれも十分速い）
- **出てくるもの**: statsmodels だけが、係数の標準誤差・95% 信頼区間・p 値を出す。scikit-learn は交差検証や前処理とつなぐ道具がそろっている。numpy は中身が全部見える
- **当たり方**: 平均の率だけを出すモデルより、はっきりよい

## 係数の読み方（距離・角度のモデル）

- 距離: -0.092。ほかが同じなら、1m 遠くなるごとに、ゴールになるオッズが 0.91倍（9% ほど下がる）
- 角度: +1.32（ラジアンあたり）。ゴールが 0.1 ラジアン広く見えると、オッズが 1.14倍
- ゴールの正面から打ったときの確率の例（このモデルの値）: 6m 38%、11m 18%、16m 10%、20m 6%、25m 4%
- 頭か体か（3つ目のモデル）: -1.02。同じ距離・角度なら、ヘディングは足よりオッズが 0.36倍。表で数えた率だけを見ると、ヘディング（12.5%）は足（10%ほど）より高いが、それはゴールの近くで打つことが多いためで、同じ場所なら足のほうが決まりやすい

## 確率の当たり具合

テストを確率の低い順に 10等分して、出した確率の平均と、実際のゴールの率を並べた（出力の表）。おおむね合っている。真ん中あたり（4・5・7 段階）はやや高く出し、いちばん上（10 段階）はやや低く出している。頭か体かを足したモデルでは、9 段階（出した確率 0.18、実際 0.21）のずれが大きい。

## 次に気になること

- 位置と体の部位のほかに、直前のイベント（クロス・スルーパス・こぼれ球）やカウンターを足すと、どれだけよくなるか
- 交差検証でシュートごとの xG を出し、選手・チーム・大会ごとに集計する（次の Issue）
- テストは 388試合・8,626本の 1回の分け方だけなので、物差しの小さな差（0.001 ほど）は分け方で変わりうる
